\section{Introduction}

The RISC-V instruction set architecture defines a family of
open standard instruction set architectures for general-purpose
computing.

This document describes the RISC-V base instruction sets and
extensions.

The instruction descriptions are organized by architectural
extension and use a common notation for operands, operations,
and instruction encodings.

\metalabel{Operation}

\[
\rd =
\left(
  \rsone\,
  \;{}_{\!\mathrm{s}}\!\times\!{}_{\!\mathrm{s}}\;\,
  \rstwo
\right)
\gg_{\mathrm{s}} XLEN
\]

\section{Base ISA}

\subsection{I --- RV32I / RV64I / RV128I --- Base Integer ISA}

The I extension defines the base integer instruction set.

\subsection{E --- RV32E / RV64E --- Reduced Integer ISA, 16 Registers}

The E extension defines a reduced integer instruction set with

% ------------------------------------------------------------
% Instruction: MULH
% ------------------------------------------------------------

\subsubsection{\instr{MULH} --- Multiply High Signed $\times$ Signed}

\metalabel{Synopsis}

\begin{lstlisting}
mulh rd, rs1, rs2
\end{lstlisting}

\metalabel{Description}

The \instr{MULH} instruction multiplies the values in the
source registers \instr{rs1} and \instr{rs2}, treating both
operands as signed two's-complement integers. The upper
\mbox{\texttt{XLEN}} bits of the resulting $2\times\mbox{\texttt{XLEN}}$-bit
product are written to the destination register \instr{rd}.

The lower \mbox{\texttt{XLEN}} bits of the product are discarded.
The operation therefore provides the high half of a signed
integer multiplication without requiring the full product to
be represented in a single integer register.

\metalabel{Operation}

\[
\rd =
\left(
  \rsone\,
  \;{}_{\!\mathrm{s}}\!\times\!{}_{\!\mathrm{s}}\;\,
  \rstwo
\right)
\gg_{\mathrm{s}} XLEN
\]

Equivalently, if the signed values represented by
\instr{rs1} and \instr{rs2} are denoted by $a$ and $b$, then
\instr{rd} receives the upper \mbox{\texttt{XLEN}} bits of the
$2\times\mbox{\texttt{XLEN}}$-bit signed product $a\times b$.
