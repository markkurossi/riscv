| I/O Port | READ(DLAB=0) | Write(DLAB=0) | ReadDLAB=1)  | Write(DLAB=1) |
| -------- | ------------ | ------------- | ------------ | ------------- |
| Base     | RBR          | THR           | DLL          | DLL           |
| Base+1   | IER          | IER           | DLM          | DLM           |
| Base+2   | IIR          | FCR           | IIR          | FCR           |
| Base+3   | LCR          | LCR           | LCR          | LCR           |
| Base+4   | MCR          | MCR           | MCR          | MCR           |
| Base+5   | LSR          | factory test  | LSR          | factory test  |
| Base+6   | MSR          | not used      | MSR          | not used      |
| Base+7   | SCR          | SCR           | SCR          | SCR           |
