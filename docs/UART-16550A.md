# UART 16550A

This page documents the UART 16550A key registers and their
values.

Many of the register tables and descriptions are derived from Lammert
Bies' excellent article, "Serial UART information":

https://www.lammertbies.nl/comm/info/serial-uart

The original material is reproduced and adapted here for convenience
and emulator development. Many thanks to Lammert for compiling and
publishing this information. Any bugs, omissions, or transcription
errors in this document are my own.

-- Markku Rossi

| -------- | ------------ | ------------- | ------------ | ------------- |
| Base     | RBR          | THR           | DLL          | DLL           |
| Base+1   | IER          | IER           | DLM          | DLM           |
| Base+2   | IIR          | FCR           | IIR          | FCR           |

| Base+6   | MSR          | not used      | MSR          | not used      |

### IER: Interrupt enable register (R/W)

Bit is set to 1 if UART should generate interrupt on event.

| Bit | Description                          |
|-----|--------------------------------------|
| 0   | Received data available              |
| 1   | Transmitter holding register empty   |
| 2   | Receiver line status register change |
| 3   | Modem status register change         |
| 4   | Sleep mode (16750 only)              |
| 5   | Low power mode (16750 only)          |
| 6   | reserved                             |
| 7   | reserved                             |

### IIR: Interrupt identification register (RO)

| Bit   | Value    | Description                        | Reset By            |
| ---   | -----    | -----------                        | --------            |
| 0     | xxxxxxx0 | Interrupt Pending                  | -                   |
|       | xxxxxxx1 | No Interrupt Pending               | -                   |
| 3,2,1 | xxxx000x | Modem status change                | MSR read            |
|       | xxxx001x | Transmitter holding register empty | IIR read, THR write |
|       | xxxx010x | Received data available            | RBR read            |
|       | xxxx011x | Line status change                 | LSR read            |
|       | xxxx110x | Character timeout (16550)          | RBR read            |
| 4     | xxx0xxxx | Reserved                           | -                   |
| 5     | xx0xxxxx | Reserved (8250, 16450, 16550)      | -                   |
|       | xx1xxxxx | 64 byte FIFO enabled (16750)       | -                   |
| 7,6   | 00xxxxxx | No FIFO                            | -                   |
|       | 01xxxxxx | Unusable FIFO (16550 only)         | -                   |
|       | 11xxxxxx | FIFO enabled                       | -                   |

### FCR: FIFO Control Register (WO)

| Bit | Value    | Description                           |
| --- | -----    | -----------                           |
| 0   | xxxxxxx0 | Disable FIFO’s                        |
|     | xxxxxxx1 | Enable FIFO’s                         |
| 1   | xxxxxx0x | -                                     |
|     | xxxxxx1x | Clear receive FIFO                    |
| 2   | xxxxx0xx | -                                     |
|     | xxxxx1xx | Clear transmit FIFO                   |
| 3   | xxxx0xxx | Select DMA mode 0                     |
|     | xxxx1xxx | Select DMA mode 1                     |
| 4   | xxx0xxxx | Reserved                              |
| 5   | xx0xxxxx | Reserved (8250, 16450, 16550)         |
|     | xx1xxxxx | Enable 64 byte FIFO (16750)           |
| 7,6 | 00xxxxxx | 1 byte receive FIFO interrupt trigger |
|     | 01xxxxxx | 4 bytes                               |
|     | 10xxxxxx | 8 bytes                               |
|     | 11xxxxxx | 14 bytes                              |

## FreeBSD transmit

```C
#define SLR_THRE 0x20
#define LSR_TEMT 0x40


while ((LSR & LSR_THRE) == 0)
  ;

IER |= IER_ETXRDY
THR = databyte

if (broken_txfifo) {
  n8250_drain(UART_DRAIN_TRANSMITTER);
  uart_sched_softih(SER_INT_TXIDLE)
} else {
  sc_txbusy = 1;
}

n8250_drain(UART_DRAIN_TRANSMITTER) {
  while (LSR & LSR_TEMT) == 0
}

// SER_INT_TXIDLE is set by IIR's IIR_TXRDY (0x2)
// xxxx001x	 - Transmitter holding register empty	IIR read or THR write

/*
 * Schedule a soft interrupt. We do this on the 0 to !0 transition
 * of the TTY pending interrupt status.
 */
void
uart_sched_softih(struct uart_softc *sc, uint32_t ipend)
{
	uint32_t new, old;

	do {
		old = sc->sc_ttypend;
		new = old | ipend;
	} while (!atomic_cmpset_32(&sc->sc_ttypend, old, new));

	if ((old & SER_INT_MASK) == 0)
		swi_sched(sc->sc_softih, 0);
}
```
